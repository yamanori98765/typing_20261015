# こつこつタイピング

日本語のことばをローマ字で入力するタイピングアプリです。練習・本番の両方で、開始前に5段階の難易度を選べます。練習は時間無制限、本番は制限時間60秒です。HTML / CSS / JavaScript だけで動き、アプリの実行に外部 API やアカウントは不要です。

## はじめる

必要なもの: Python 3（ローカル配信用）。テストには Node.js 24 と npm、および Chromium を使用します。

```sh
cd /workspace/typing_20261015
npm start
```

`npm start` は Python の HTTP サーバーをポート 8000 で起動します。手元の PC ではブラウザから `http://localhost:8000` を開いてください。クラウド環境での画面表示は利用環境のポート転送機能に従ってください。停止は Ctrl+C です。依存パッケージの導入やビルドは、アプリを遊ぶだけなら不要です。

## 遊び方

1. モードで「練習（時間無制限）」または「本番（60秒）」を選びます。
2. どちらのモードでも、最初に難易度を選んで開始ボタンを押します。開始前に出題の英字文字数・問題数が表示されます。
3. 日本語入力（IME）をオフにし、表示されたローマ字を半角英字で入力します。
4. 間違えた場合は、下線の文字をもう一度入力します。Backspace は不要です。
5. 練習は「練習を終える」、本番は60秒経過で結果を表示します。両方とも全8問をクリアすると終了します。「やり直す」は同じ設定で最初から始めます。

プレイ中はモード・難易度を変更できません。練習は終了ボタンで、本番は時間切れで終了してから切り替えてください。

| 難易度（練習・本番共通） | 英字の文字数 | 内容 |
| --- | --- | --- |
| 1 やさしい | 2〜5文字 | 短いことば |
| 2 ふつう | 5〜6文字 | 身近なことば |
| 3 むずかしい | 7〜9文字 | 長めのことば |
| 4 上級 | 10〜16文字 | 短いフレーズ |
| 5 達人 | 17〜40文字 | 長い文章 |

各モード×各難易度に別々の8問、合計80問を用意しています。実際の最短・最長文字数は開始前の画面に表示します。同じプレイ内では同じ問題を二度出さず、全問クリアで終了します。再スタートすると新しい順番で出題します。同じ英字が別のことばに含まれることはあります。

本番は全レベル同じ採点方式です。文章も空白や句読点なしで、表示された英字を入力します。

- 正解1文字につき10点、ミス1文字につき5点減点（最低0点）。大文字も受け付けます。
- 正確率は正解文字数 ÷（正解文字数＋ミス数）。未入力時は100%です。
- ベストスコアは練習・本番の各レベル別に、同じブラウザの localStorage に保存します。出題内容の変更に合わせて保存キーを変更しているため、以前のベストとは別記録になります。保存が無効でも練習できます。端末間の同期はありません。
- 問題は重複なしでランダムに選びます。問題を使い切ったら終了するため、同じ問題を繰り返すことはありません。
- 表示どおりのつづりのみ対応します。例: `shi` を `si` と入力するなどの別表記には未対応です。貼り付けは受け付けません。
- スマートフォンでも入力できます。英字キーボードに切り替えてください。

## 開発・検証

```sh
npm ci --cache /tmp/typing-npm-cache
npm test
npm run check
npm run test:e2e
```

- `npm test`: 入力判定、ミス、得点、制限時間、リスタート、出題を Node.js のテストで検証します。
- `npm run check`: アプリの JavaScript 構文を検証します。
- `npm run test:e2e`: Chromium で開始・入力・ミス・終了・自己ベスト保存・リスタート・モバイル幅を検証します。専用サーバーを自動起動するため、先にポート8000を空けてください。

ブラウザテストは既定で `/usr/bin/chromium` を使います。別の場所にある場合は `CHROMIUM_PATH=/path/to/chromium npm run test:e2e` と指定してください。Chromium が未導入なら OS の信頼できるパッケージ管理機能で導入してください。

クラウド環境では上記の全チェック（単体6件・ブラウザ4件）が成功しました。ブラウザテストでは時計を進め、本番全5レベルの60秒の時間切れ、練習の時間無制限・手動終了、全10種類の全問クリア・重複防止、モード・難易度別のベスト保存も検証しています。実機スマートフォンでの IME や全ブラウザの互換性は未検証です。

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| `index.html` | 日本語画面、入力欄、結果表示 |
| `style.css` | レスポンシブな画面デザイン |
| `game.js` | 出題、入力判定、時間、スコア |
| `app.js` | DOM 操作、入力イベント、自己ベスト保存 |
| `tests/game.test.js` | ゲームロジックの単体テスト |
| `tests/browser/typing.spec.js` | 実ブラウザでの操作テスト |

問題の追加は `game.js` の `QUESTION_BANKS` のモード・難易度ごとの配列を編集します。文字数は `LEVELS` の範囲を守ってください。ビルド工程はありません。配布するときは `index.html`・`style.css`・`game.js`・`app.js` を静的ホスティングに配置してください。Python の HTTP サーバーは開発確認用です。

## GitHub Pages で公開する

GitHub のリポジトリ設定で **Settings → Pages → Build and deployment** を開き、Source を **Deploy from a branch**、Branch を **main**、フォルダを **/ (root)** にして Save を押します。GitHub Pages のデプロイが成功すると設定画面に公開リンクが表示されます。

`.nojekyll` を配置し、静的ファイルをそのまま配信する構成です。公開対象には機密情報を置かないでください。
